  3) Centinela OTA (si también copiás updates/)

     - ApolloSetup.exe / ApolloSetup_x64.exe con fix OTA (UAC + paro de servicio)

================================================================================
TAREA PARA EL AGENTE CURSOR — EJECUTAR EN ORDEN
================================================================================

1) COPIAR DESDE EL PUENTE

   $puente = "\\192.168.11.20\Puente\ApolloSupport"
   if (-not (Test-Path $puente)) { $puente = "Y:\ApolloSupport" }
   if (-not (Test-Path $puente)) { throw "No se encuentra el puente ApolloSupport" }

   # Backend
   Copy-Item "$puente\backend\main.py"    "C:\ApolloSupport\backend\main.py" -Force
   Copy-Item "$puente\backend\schemas.py" "C:\ApolloSupport\backend\schemas.py" -Force

   # Frontend compilado (MIR = espejo completo del dist)
   robocopy "$puente\frontend\dist" "C:\Apache24\htdocs\apollosupport" /MIR /R:2 /W:3
   # robocopy exit 0-7 = OK

   # Opcional — OTA Centinela 3.3.7 (solo si querés publicar el instalador nuevo)
   New-Item -ItemType Directory -Force -Path "C:\ApolloSupport\backend\updates" | Out-Null
   Copy-Item "$puente\backend\updates\version.json"      "C:\ApolloSupport\backend\updates\version.json" -Force
   Copy-Item "$puente\backend\updates\ApolloSetup.exe"   "C:\ApolloSupport\backend\updates\ApolloSetup.exe" -Force
   Copy-Item "$puente\backend\updates\ApolloSetup_x64.exe" "C:\ApolloSupport\backend\updates\ApolloSetup_x64.exe" -Force

2) REINICIAR BACKEND

   nssm restart ApolloBackend
   # Si nssm no está en PATH:
   #   C:\ApolloSupport\backend\venv\Scripts\nssm.exe restart ApolloBackend
   # Alternativa:
   #   Restart-Service ApolloBackend -Force
   #   sc stop ApolloBackend && timeout /t 3 && sc start ApolloBackend

3) VERIFICAR

   sc query ApolloBackend
   # STATE debe ser RUNNING

   curl.exe -s http://127.0.0.1:8001/docs -o NUL -w "backend_http=%{http_code}`n"
   # Esperado: 200

   type C:\Apache24\htdocs\apollosupport\version.txt
   # Debe mostrar:
   #   version=3.2.6
   #   build=2026-09-20-ae
   #   sw=/sw-v3.2.6.js

   # Opcional OTA:
   curl.exe -s http://127.0.0.1:8001/api/centinela/update_check
   # Si copiaste updates/: version "3.3.7"

4) NO TOCAR EN ESTE SERVIDOR (salvo pedido explícito)

   - No modificar .env ni credenciales DB
   - No hacer commit git
   - No reinstalar Centinela en este servidor (eso es en PCs cliente)
